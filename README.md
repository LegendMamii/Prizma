
# 🔮 Prizma

**TR:** Rögue-lite tuğla kırma oyunu. Topu raketle zıplat, kristalleri kır; prizma kristali topu böler, patlayıcı kristaller zincir kurar. Her seviye sonunda yeni bir güç seç ve bir sonraki seviyeye daha güçlü gir.
**EN:** A roguelite brick-breaker. Bounce the ball, shatter crystals; prism crystals split the ball, explosive ones chain. Pick a new power after every level.

Tek dosya, sıfır bağımlılık. / Single file, zero dependencies.

## Özellikler / Features

- 7 farklı seviye deseni, giderek sertleşen kristaller; kristaller zamanla **iner**, kırmakta geç kalırsan can kaybedersin
- Her vuruşta hasar sayıları, kırılınca kazanılan puan uçuyor
- Kristal türleri: normal, **prizma** (topu böler), **patlayıcı** (zincir reaksiyon), **altın** (garanti kapsül + bonus)
- Güç kapsülleri: geniş raket, çoklu top, yavaş zaman, ateş topu, ekstra can
- 10 kalıcı koşu gücü (Ağır Top, Yankı, Zincir, Mıknatıs, Mıknatıs…) her seviye sonunda 3 seçenekten biri
- Kombo çarpanı, gökkuşağı top izi, ekran sarsıntısı, kombo ile yükselen notalar, ambient müzik
- Menüde kendi kendine oynayan demo, en iyi skor kaydı, mobil dokunmatik destek
- Türkçe / İngilizce

## Kontroller / Controls

| | |
|---|---|
| Hareket / Move | Fare, parmak sürükle, `←` `→` / `A` `D` |
| Fırlat / Launch | Dokun, tıkla veya `Boşluk` / tap, click or `Space` |
| Güç seç / Pick power | `1` `2` `3` veya tıkla |
| Duraklat / Pause | `P` / `Esc` |
| Ses / Sound | `M` |
